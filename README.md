# BanquitoBank

Sistema bancario desarrollado en PHP con autenticación de sesiones 
y gestión de transacciones.

## Tecnologías
- PHP
- HTML/CSS
- XAMPP

## Funcionalidades
- Registro e inicio de sesión de usuarios
- Depósitos y retiros
- Historial de transacciones
- Panel de administración

## Cómo ejecutarlo
1. Clonar el repositorio
2. Copiarlo en C:\xampp\htdocs\
3. Iniciar Apache en XAMPP
4. Abrir http://localhost/BanquitoBank
